# Podry

轻量级云原生集群管理与 CI/CD 平台，面向个人开发者与中小团队。

A lightweight cloud-native cluster management and CI/CD platform for individual developers and small teams.

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Status](https://img.shields.io/badge/status-early%20development-orange.svg)]()

## 适合谁 / Who It's For

独立开发者：一个人也要有靠谱的发布流程 / Solo developers who still want a reliable release flow

中小团队：不想为 CI/CD 养一套重型平台 / Small teams avoiding heavyweight platforms

云原生入门：概念对齐 K8s，学了就能用 / K8s newcomers who want concepts that map directly
