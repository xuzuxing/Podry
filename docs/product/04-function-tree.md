# 功能树

版本 V1.0 / 日期：2026-11-20 · 配套：[功能点清单](03-function-inventory.md)（逐项字段与缺口）、[HTTP 接口分期矩阵](../backend/03-api-delivery-matrix.md)（后端排期）

## 4. 树的三条阅读规则

1. **一级节点就是全局菜单**：工作台（项目/应用）、集群资源、操作记录、平台设置。构建、发布、配置、环境覆盖都在"应用工作台"下面，不做全局菜单。
2. **`★` 是前后端对齐线**：★ 的 42 个是前端首版要画的页面，对应后端 B1–B5；没有 ★ 的是管理增强与 P1/P2 能力，前端首版不显示入口。
3. **同一端点可在两处出现**（`RL-02`、`RL-03`、`EX-01` 在应用内与集群内各一次）：这是刻意的——两处保留各自上下文，但共用同一套组件与接口，不复制业务逻辑。
